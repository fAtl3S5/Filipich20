# Ограничение: чтение группы комментариев

Удаление сообщений и kick/ban закрывают публикацию и формальное членство.

Связка Telegram «канал → discussion group» **не даёт** боту гарантированно запретить *чтение* истории комментариев, если клиент открывает тред через кнопку под постом канала без полноценного join.

## Что делать до production

1. Канал и группа — только private, без username и открытых инвайтов.
2. Join requests + проверка подписки на сообщениях в группе.
3. Тест с аккаунта без подписки: виден ли тред после kick/ban.
4. Если чтение всё ещё возможно — не заявлять полную защиту; рассмотреть отключение discussion или отдельный закрытый чат только по инвайту с join request.

Подробности в коде: `DISCUSSION_READ_LIMITATION` в `app/services/access.py` и раздел README.
